# MASTER-L-Systems

Master's thesis in Computer Graphics

## Plan

1. Setup OpenGL environment
2. Setup GTest framework
3. Setup Doxygen documentation

## Installation

1. Clone the repository with submodules

```bash
git clone --recurse-submodules git@github.com:tudny/MASTER-L-Systems.git
```

```bash
git clone --recurse-submodules https://github.com/tudny/MASTER-L-Systems.git
```

2. Install dependencies


```bash
sudo apt install xorg-dev libglu1-mesa-dev libglfw3 libglfw3-dev libxkbcommon-dev
```

For building the documentation you need to install Doxygen

```bash
sudo apt install doxygen graphviz
```
